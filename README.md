# Zaereen Accommodation & Google Sheets Reservation Manager

## Overview
This application streamlines reservation management and logistics for Zaereen accommodations. It acts as an intelligent assistant to parse booking details and organize them for seamless integration into our Google Sheets tracking workflows.

## Features
* **Automated Data Formatting:** Extracts guest names, arrival/departure dates, and group sizes, converting them into structured formats ready for spreadsheet entry.
* **Property Management:** Assists with administrative workflows for housing sites including DOCTOR HOUSE, BADRI, BURHANI, and MOHAMMADI.
* **Bilingual Support:** Processes requests and drafts official notices in both English and Arabic.
* **Standardized Documentation:** Ensures all generated workflows use correct administrative terminology, such as "Taeed Sakan" for housing documents and routing approvals to the "Masool".

## Usage
1. Enter the required Gemini API Key to unlock the interface.
2. Paste raw booking details or administrative queries into the chat.
3. Copy the AI-formatted output directly into the master spreadsheet tracker.
